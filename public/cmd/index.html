Navegação de Pastas e Arquivos

  • dir - Mostra os arquivos, pastas, data e tamanho.
  • cd nome_da_pasta - Mudar de pasta
  • cd .. - Voltar para a pasta anterior

Manipulação de Arquivos e Pastas

  • mkdir nome_da_pasta - Criar uma nova pasta
  • type nul > arquivo.txt - Criar um arquivo vazio em lote
  • copy arquivo.txt destino\ - Copiar arquivos
  • move arquivo.txt novapasta\ - Mover arquivos
  • rename arquivo.txt novo-nome.txt - Renomear arquivos
